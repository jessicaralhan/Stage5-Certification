## Unified Recommendations

### HIGH

1. **Apply a key policy to `aws_kms_key.logs`.**
   - Add a `data "aws_caller_identity" "current" {}` block if it does not already exist.
   - Set `policy = jsonencode(...)` on `aws_kms_key.logs` with two statements:
     - `EnableRootAdmin`: `Allow` for `arn:aws:iam::${data.aws_caller_identity.current.account_id}:root` with `kms:*` on `*`.
     - `AllowCloudTrailEncrypt`: `Allow` for the service principal `cloudtrail.amazonaws.com` with `kms:GenerateDataKey*` and `kms:DescribeKey` on `*`, conditioned on `aws:SourceAccount` equal to the account ID.
   - This is an in-place update. Confirm with `terraform plan` that no replacement is scheduled.
   - After apply, verify delivery with `aws cloudtrail get-trail-status --name <trail>` and confirm that `LatestDeliveryError` is empty.

### MEDIUM

2. **Break the self-logging loop on `aws_s3_bucket_logging.logs`.**
   - Point `target_bucket` to a separate, dedicated access-log bucket rather than `aws_s3_bucket.logs.id`.
   - Set a `target_prefix` so access logs are easy to identify.
   - Apply a lifecycle rule to the access-log bucket to expire old logs.
   - No remediation was generated for this finding. This recommendation is implementation guidance and should be validated during the next review cycle.

3. **Add a lifecycle configuration to `aws_s3_bucket_versioning.logs`.**
   - Add an `aws_s3_bucket_lifecycle_configuration` resource with a rule that expires noncurrent versions after a retention period that meets your compliance requirements.
   - Set the retention value in consultation with the audit and compliance team, since audit logs are often subject to minimum retention periods.
   - Confirm that `bucket_key_enabled = true` is set on the bucket's server-side encryption configuration.

### LOW

4. **Enforce TLS on `aws_s3_bucket_policy.trail`.**
   - Add a statement with `Effect = "Deny"`, `Principal = "*"`, `Action = "s3:*"`, resources covering the bucket and its objects, and `Condition = { Bool = { "aws:SecureTransport" = "false" } }`.
   - No remediation was generated for this finding. This recommendation is implementation guidance and should be validated during the next review cycle.
