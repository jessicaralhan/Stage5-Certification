## Findings by Domain

### Infrastructure (Terraform) Findings

Risk Level: **HIGH**

### Destructive Changes

No destructive changes were identified. The plan does not replace or delete any resource.

### Security Exposure

**❌ HIGH: CloudTrail cannot encrypt log delivery to the audit bucket**
- **Resource**: `aws_kms_key.logs`
- **Exposure type**: Missing service grant in key policy
- **Issue**: The key has no key policy granting `cloudtrail.amazonaws.com` the `kms:GenerateDataKey*` permission.
- **Impact**: CloudTrail writes to the SSE-KMS audit bucket will likely fail. Audit logging may be silently broken, which creates a compliance and detection gap with no obvious alert.
- **Why it matters**: Audit trails are the primary evidence source for incident response and compliance attestations. A gap here can go unnoticed until an investigation requires the missing data.

**⚠️ MEDIUM: Non-TLS requests to the audit bucket are not denied**
- **Resource**: `aws_s3_bucket_policy.trail`
- **Exposure type**: Missing transport-security enforcement
- **Issue**: The policy has no `Deny` statement for `aws:SecureTransport = false`.
- **Impact**: Plaintext HTTP requests to the audit log bucket are not blocked, so log data and credentials could be exposed in transit.
- **Why it matters**: Enforcing TLS on the audit bucket is a common baseline control and is frequently checked by compliance audits.

**⚠️ MEDIUM: Audit log versions can be permanently deleted without MFA**
- **Resource**: `aws_s3_bucket_versioning.logs`
- **Exposure type**: MFA Delete disabled
- **Issue**: `mfa_delete = "Disabled"`, so object versions can be permanently deleted without MFA.
- **Impact**: A compromised principal with `s3:DeleteObjectVersion` could destroy audit history, including the evidence needed to detect that compromise.
- **Why it matters**: Protecting log integrity against deletion is central to tamper-evident logging.

**▫️ LOW: CloudTrail PutObject is not scoped to the specific trail**
- **Resource**: `aws_s3_bucket_policy.trail`
- **Exposure type**: Overly broad write condition
- **Issue**: The CloudTrail `PutObject` statement conditions only on `aws:SourceAccount` and lacks an `aws:SourceArn` condition.
- **Impact**: Any trail in the same account could write to this bucket. This is a weaker confused-deputy boundary than necessary.

**▫️ LOW: TLS condition uses a non-idiomatic operator**
- **Resource**: `aws_s3_bucket_policy.trail`
- **Exposure type**: Fragile policy condition
- **Issue**: `aws:SecureTransport` is evaluated with `StringEquals` against the string `"true"` instead of a `Bool` condition.
- **Impact**: The condition works in common cases but is fragile and does not follow AWS policy best practice.

**▫️ LOW: Short KMS deletion recovery window**
- **Resource**: `aws_kms_key.logs`
- **Exposure type**: Short recovery window
- **Issue**: `deletion_window_in_days = 10`, which is close to the 7-day minimum.
- **Impact**: If the key is scheduled for deletion, the recovery window is short. Deletion would make audit logs unreadable, and the window may not be enough for a deliberate or accidental deletion to be noticed and reversed.

### Cost Impact

The analyzer did not assign severity to these items.

- **`aws_kms_key.logs`**: Adds a customer-managed KMS key at about $1/month. `bucket_key_enabled = true` reduces per-request KMS charges on the audit bucket.

### Proposed Remediation for `aws_kms_key.logs`

The following key policy was proposed by the remediation generator. It grants account root full administrative access and grants CloudTrail the encryption permissions it needs, scoped to the account and to trails in that account:

```hcl
policy = jsonencode({
  Version = "2012-10-17"
  Statement = [
    {
      Sid       = "EnableAccountAdmin"
      Effect    = "Allow"
      Principal = { AWS = "arn:aws:iam::${data.aws_caller_identity.current.account_id}:root" }
      Action    = "kms:*"
      Resource  = "*"
    },
    {
      Sid       = "AllowCloudTrailEncrypt"
      Effect    = "Allow"
      Principal = { Service = "cloudtrail.amazonaws.com" }
      Action    = ["kms:GenerateDataKey*", "kms:DescribeKey"]
      Resource  = "*"
      Condition = {
        StringEquals = {
          "aws:SourceAccount" = data.aws_caller_identity.current.account_id
        }
        StringLike = {
          "kms:EncryptionContext:aws:cloudtrail:arn" = "arn:aws:cloudtrail:*:${data.aws_caller_identity.current.account_id}:trail/*"
        }
      }
    }
  ]
})
```
