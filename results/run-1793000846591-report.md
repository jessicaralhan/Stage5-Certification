## Unified Recommendations

### Priority 1: MEDIUM — Restrict CloudTrail S3 Bucket Policy

**Resource:** `aws_s3_bucket_policy.trail`

**Action:**
Modify the S3 bucket policy to restrict `s3:PutObject` permission to CloudTrail-specific object prefixes and add MFA/account-level conditions.

**Implementation:**
```hcl
# Update the Resource field in aws_s3_bucket_policy.trail
"Resource": "arn:aws:s3:::trail-bucket/AWSLogs/ACCOUNT-ID/*"

# Add a condition to enforce CloudTrail requirements
"Condition": {
  "StringEquals": {
    "s3:x-amz-acl": "bucket-owner-full-control"
  }
}
```

**Rationale:** Restricts CloudTrail writes to the `/AWSLogs/ACCOUNT-ID/` prefix, preventing arbitrary object creation in other paths. The `bucket-owner-full-control` condition enforces CloudTrail's required ACL setting.

---

### Priority 2: MEDIUM — Enable MFA Delete on Logs Bucket

**Resource:** `aws_s3_bucket_versioning.logs`

**Action:**
Enable MFA delete protection on the versioned logs bucket to require MFA authentication for permanent object deletion.

**Implementation:**
```hcl
resource "aws_s3_bucket_versioning" "logs" {
  bucket = aws_s3_bucket.logs.id
  
  versioning_configuration {
    status     = "Enabled"
    mfa_delete = "Enabled"
  }
}
```

**Prerequisites:** Requires root AWS account credentials with an MFA device configured. This is a one-time setup that AWS enforces at the account level.

**Rationale:** MFA delete ensures that even principals with `s3:DeleteObject` permission cannot permanently remove object versions without completing MFA authentication, protecting audit log integrity.

---

### Priority 3: MEDIUM — Add Lifecycle Policy to Logs Bucket

**Resource:** `aws_s3_bucket_logging.logs`

**Action:**
Implement a lifecycle configuration to automatically delete old log objects after 90 days, preventing unbounded growth.

**Implementation:**
```hcl
resource "aws_s3_bucket_lifecycle_configuration" "logs" {
  bucket = aws_s3_bucket.logs.id

  rule {
    id     = "delete-old-logs"
    status = "Enabled"

    expiration {
      days = 90
    }
  }
}
```

**Rationale:** Automatically removes objects older than 90 days, preventing the logs bucket from growing indefinitely and incurring runaway storage costs. Retention period (90 days) should be adjusted to match your compliance or operational requirements.
