- **Forcing Attribute**: `db_subnet_group_name`

- **Why It Matters**: Replacing the cluster deletes the existing database, and any data not captured in a snapshot is lost. Applications lose database connectivity for the duration of the rebuild. This change is not reversible without a restore.
- **Recommendation**: Do not apply this plan as written. See Unified Recommendations, item 1.

### Security Exposure

⚠️ **MEDIUM**: Database audit and error logs are not exported.
- **Resource**: `aws_rds_cluster.prod`
- **Exposure Type**: Missing `enabled_cloudwatch_logs_exports`
- **Impact**: Audit, error, and slow-query logs are not sent to CloudWatch. Investigating a security incident or performance problem on production will lack the necessary evidence.

⚠️ **MEDIUM**: Production cluster has no deletion safeguard.
- **Resource**: `aws_rds_cluster.prod`
- **Exposure Type**: `deletion_protection` not set (defaults to `false`)
- **Impact**: The cluster can be deleted with a single API call or Terraform destroy, with no additional confirmation step.

⚠️ **MEDIUM**: Cluster may inherit the VPC default security group.
- **Resource**: `aws_rds_cluster.prod`
- **Exposure Type**: `vpc_security_group_ids` not set
- **Impact**: The cluster may fall back to the VPC default security group, which can allow broader network access than the workload requires.

ℹ️ **LOW**: Master username uses the common default value.
- **Resource**: `aws_rds_cluster.prod`
- **Exposure Type**: `master_username` set to `admin`
- **Impact**: A well-known username makes credential-guessing attacks easier. This is a weak control on its own but reduces the effort required for an attacker.

ℹ️ **LOW**: KMS key deletion window is at the minimum.
- **Resource**: `aws_kms_key.rds`
- **Exposure Type**: `deletion_window_in_days` set to 7
- **Impact**: If the key is scheduled for deletion by mistake, only 7 days are available to cancel it. Once deleted, all data encrypted with the key becomes unrecoverable.

### Cost Impact

## Unified Recommendations

**1. CRITICAL: Prevent replacement of `aws_rds_cluster.prod`**
- Set `db_subnet_group_name = aws_db_subnet_group.prod.name` on `aws_rds_cluster.prod` so that it references the existing subnet group.
- Add `lifecycle { prevent_destroy = true }` to `aws_rds_cluster.prod`. Terraform will then refuse any plan or apply that would destroy the cluster.
- Run `terraform plan` and confirm that `aws_rds_cluster.prod` shows no replacement (no `-/+` or `forces replacement` markers) before proceeding.
- If the subnet group must change, treat it as a separate change request. Require a verified manual snapshot of `aws_rds_cluster.prod`, a documented rollback plan, a planned maintenance window, and explicit approval from the database owner.

**2. MEDIUM: Add deletion protection to `aws_rds_cluster.prod`**
- Set `deletion_protection = true`. This prevents deletion through the AWS API and Terraform until the flag is disabled.

**3. MEDIUM: Export database logs from `aws_rds_cluster.prod`**
- Set `enabled_cloudwatch_logs_exports = ["audit", "error", "slowquery"]`.
- Confirm that the CloudWatch log group retention meets the organization's audit requirements.

**4. MEDIUM: Assign explicit security groups to `aws_rds_cluster.prod`**
- Set `vpc_security_group_ids` to a dedicated security group that allows inbound MySQL traffic (port 3306) only from the application security groups that need database access.
- Confirm that the VPC default security group does not allow inbound database traffic.

**5. LOW: Change the master username on `aws_rds_cluster.prod`**
- Replace `admin` with a non-default username. Changing `master_username` on an existing cluster forces replacement, so schedule this together with item 1 or as part of the separate change request.
- Store the credentials in AWS Secrets Manager and enable automatic rotation.

**6. LOW: Increase the KMS deletion window on `aws_kms_key.rds`**
- Set `deletion_window_in_days` to a higher value, such as 30. This gives more time to cancel an accidental deletion.

**7. Cost review (no blocking action)**
