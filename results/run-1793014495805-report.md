⚠️ **MEDIUM**: RDS cluster disables IAM database authentication.

   - **Impact**: Cannot use AWS IAM roles or temporary credentials for database access; increases credential management burden; cannot enforce least-privilege access via IAM policies; audit trail does not include IAM identity information
   - **Recommendation**: Set `iam_database_authentication_enabled = true` and update application connection strings to use IAM auth tokens
