### Remediations

**Recommended Fix for `aws_ec2_security_group.app`:**

Replace the unrestricted egress rule with explicit least-privilege egress rules. Example configuration:

```hcl
egress {
  from_port   = 443
  to_port     = 443
  protocol    = "tcp"
  cidr_blocks = ["<required-destination-cidr>"]
}
```

**Actions Required:**
1. Identify all required outbound destinations (by CIDR, security group, or service)
2. Remove any egress rule with `cidr_blocks = ["0.0.0.0/0"]` and `protocol = "-1"`
3. Add explicit egress rules for each required destination, protocol, and port
4. Re-submit the plan for approval once least-privilege egress is configured
